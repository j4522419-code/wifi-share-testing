Connecting

Either person can send one file at a time. The recipient must approve each incoming file.

Files travel directly between browsers using WebRTC data channels. No PocketBridge server stores or relays them. Direct connections work on many networks, but restrictive routers may block them; this prototype has no paid relay. Both devices must stay online with this page open. Peer-to-peer data channels use DTLS encryption as part of WebRTC. See RFC 8827.
